# SODAX Cross-Chain Consolidator ("Dust Sweeper")

A Next.js app that lets users consolidate scattered major-asset fragments across
EVM chains + Solana into one token on one chain, routed through the SODAX SDK.
Earns a 0.15% partner fee on every swap.

See [PLAN.md](./PLAN.md) for the full build plan. Greenfield — not yet scaffolded.

Built on @sodax/sdk@2.0.0-rc.8.
